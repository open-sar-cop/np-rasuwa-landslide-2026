Public, unofficial common operating picture for the 26 August 2026 ice-rock avalanche and debris flow that hit **Gyirong Port (吉隆口岸)** on the China side and **Rasuwagadhi / Timure / Bhote Koshi–Trishuli** on the Nepal side.

This is **not** NDRRMA, Nepal Police, or a Chinese command net.
