类似 Liveuamap / DeepState 的**公开灾情动态**，不是军方指挥网。

语言：中文 / English / नेपाली / हिन्दी

打开 `index.html` 或 Pages：https://open-sar-cop.github.io/np-rasuwa-landslide-2026/live/

- 地图钉、时间线、用户上报、评论、本地审核

- `i18n.js` 语言包
- `snapshot.schema.json` 定时任务写入格式
- `collect.py` 官方源探活

数字以 NDRRMA / 中方发布会为准。非官方。
