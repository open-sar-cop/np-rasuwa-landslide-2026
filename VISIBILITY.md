# How people actually find this

GitHub Pages is public. Search engines and chatbots will not see it unless other sites link here.

## Do these first (highest yield)

1. Repo About box (GitHub UI): set Description to
   `Public COP for the 26 Aug 2026 Rasuwa / Gyirong debris flow. Unofficial.`
   Homepage: `https://open-sar-cop.github.io/np-rasuwa-landslide-2026/`
   Topics: `nepal` `rasuwa` `gyirong` `disaster-response` `open-data` `humanitarian` `copernicus` `unosat`

2. Pin the repo on the `open-sar-cop` org profile.

3. Add this URL to the OSM wiki page
   https://wiki.openstreetmap.org/wiki/Organised_Editing/Activities/Nepal_Floods_2026
   under Other resources.

4. Submit the Pages URL as a source on ReliefWeb / HDX discussion, not as official casualty data.

5. One post on X with: map screenshot + Pages link + `#Rasuwa` `#GyirongPort` `#NepalFloods` and tag `@NDRRMA` only as FYI, never as if you speak for them.

6. Tell HOT / NAXA / ICIMOD / UNOSAT feedback email that a public COP exists. They already map the event.

## Then

- English + Chinese README (done in this repo) so Google and LLM crawlers index both names: Rasuwa and 吉隆口岸.
- Keep `llms.txt` at repo root so assistants can quote a short fact card.
- Do not advertise user-upload as verified. That will get you ignored by agencies.
